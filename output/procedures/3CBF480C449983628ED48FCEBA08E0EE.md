# Re-inspection request

The steps to create/assign an Est – Re-inspect Vehicle activity.

### When this applies

When a body shop requests vehicle re-inspection, a Claims Support Assistant (CSA) forwards the request to the estimator group.

### Procedure

1. Claims Support Assistant will receive a phone call or email requesting a vehicle re-inspection.
2. Gather the details of the request.

   Details include

   * claim number
   * vehicle description
   * location of the vehicle
3. Access the claim, create an Est – Re-inspect Vehicle activity and include activity details.

   Details include

   * collision repair facility name
   * location of the vehicle
4. Assign the Est – Re-assign Vehicle activity.

   The activity must be assigned to

   * the Mobile Estimating Assignment queue, and
   * assignment location within that servicing area.
