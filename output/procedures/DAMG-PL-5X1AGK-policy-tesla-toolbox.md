# Perform Tesla Diagnostics policy

Tesla diagnostics can be accessed through the Toolbox or the
infotainment system. Tesla vehicles use system alerts rather than traditional fault codes that
are found when using a standard on-board diagnostics (OBD) II port. These alerts are stored in
the vehicle's system and are accessed through vehicle diagnostics.

### Policy

Tesla service manuals and collision repair procedures may require the participant to verify system stored alerts, fault codes and calibrate certain systems within the vehicle as part of the repair process. ICBC pays the following allowances for successful calibrations performed when the collision repair program participant provides an original equipment manufacturer repair procedures.

### Allowance

Labour time allowances for Tesla repairs are reimbursed at ICBC's body labour rate.

| Repair type | Labour time allowance |
| --- | --- |
| Tesla Toolbox access Note: Participant must supply OE Procedure to support if toolbox hookup is required. | 0.7 hour Note: Must be entered in Mitchell Cloud Estimating (MCE) through My Template "ACCESS TESLA TOOLBOX". |
| Diagnose and clear fault codes (Diagnostic Trouble Codes DTC) through Service Mode, if required. | 0.3 hour Note: Must be entered in Mitchell Cloud Estimating (MCE) through My Template "DIAGNOSE/CLEAR FAULT CODES". |
| System calibration: first calibration (with Tesla or without Toolbox) | 0.3 per calibration. For example, Windshield calibration |
| Enabling and disabling Service Mode (Stand-alone operation) | Included (Stand alone operation) |
| Over-the-air software updates (Stand-alone operation) | Included (Stand alone operation) |

Important: Pre and post-repair scanning cannot be billed in addition on Tesla vehicles.

Example of Tesla system calibrations. Must be entered in Mitchell Cloud Estimating (MCE) through My Templates and supported with current OEM repair procedure.

| Tesla system calibration | Includes |
| --- | --- |
| 360 CAMERA | B pillar applique cameras, and front fender cameras |
| SEAT CALIBRATIONS | All seats within vehicle |
| WINDSHIELD CAMERA | Pitch verification |
| LT AND RT HEADLAMPS | Left and right headlamps |
| ALL DOORS SIDE GLASS | Left front, left rear, right front, right rear |
| FALCON WING DOORS (MODEL X ONLY) | Left and right door |
| ALL DOOR HANDLES (MODEL S ONLY) | Left front, left rear, right front, right rear |
| CHARGE PORT DOOR | -- |
| STEERING ANGLE SENSOR | If four-wheel alignment is performed (includes test drive of vehicle) |
| COOLANT PURGE | -- |
| WAVE RADAR SENSORS | If applicable |
| ALL SAFETY RESTRAINT SYSTEMS | SRS and seatbelt within vehicle |
| PARKING SENSORS | Test, reset and reprogram |

Note: Instances where a software update has been performed, and the system no longer requires calibration, the repair facility is not permitted to charge for calibration of that system.
