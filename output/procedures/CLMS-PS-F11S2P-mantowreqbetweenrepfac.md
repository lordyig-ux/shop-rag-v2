# Manage a tow request to a sublet repair facility

Claims support assistants manage requests from collision repair program facilities for tows to a sublet repair facility.

### When this applies

Collision repair program participants can request a tow to another repair facility without ICBC approval when there is a repair requirement that the originating facility cannot complete or perform, including the removal of major mechanical components. These facilities are not permitted to request that ICBC facilitate a tow to another collision repair program facility.

Note: If the vehicle can be driven to the sublet repair facility, requests must not be made to tow the vehicle.

### Process

1. **Collision repair program participant**
   1. Completes the Repair Facility Support Request form - Towing request to tow the vehicle 

      * from the repair program participant location
      * to the sublet repair facility.

      Tip: A collision repair program participant can access the Repair Facility Support Request form through [Make a support request (partners.icbc.com)](https://www.icbc.com/partners/material-damage/collision/pages/make-support-request.aspx).
   2. Ensures that the sublet facility is aware of the delivery of the vehicle.
   3. Determines if the vehicle must be towed to a different repair facility.
   4. Submits the Repair Facility Support Request form- Towing request

      Important: ICBC approval is not required.

   **Result:**  
   A [Repair Facility - Tow to Shop activity](CCUG-RF-6C3HGW-repair-facility-tow-shop.html "The activity is created when a repair facility submits a Facility to Facility Towing Request through the .") is created on the claim.
2. **Claims support assistant**
   1. Processes tow request.

   Note: Once the tow and repairs are completed, there is a secondary tow request from the sublet facility back to the originating collision repair facility. This is the responsibility of the originating facility.
3. **Collision repair program participant**
   1. Completes secondary Repair Facility Support Request form - Towing request to tow the vehicle 

      * from the sublet repair facility
      * to the repair program participant location.

   **Result:**  
   A [Repair Facility - Tow to Shop activity](CCUG-RF-6C3HGW-repair-facility-tow-shop.html "The activity is created when a repair facility submits a Facility to Facility Towing Request through the .") is created on the claim.
4. **Claims support assistant**
   1. Processes tow request.
