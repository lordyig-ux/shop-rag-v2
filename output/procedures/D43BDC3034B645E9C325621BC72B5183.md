# Removal and installation time and estimates

Summary of the removal and installation times that are applied to the estimate.

### Applying removal and installation (Re&I) time

When the repair facility needs to remove a part to assist in a repair the following times are allowed:

| When the removal and installation time is ... | Then the estimator ... |
| --- | --- |
| listed in the Mitchell software | applies the listed Mitchell Cloud Estimating (MCE) time. |
| listed in another reference manual | applies the listed time. |
| * not listed, or * required for a partial removal | allows a reasonable judgment time/allowance. |

### Re-taping mouldings and nameplates

Re-taping is not included in the removal and installation labour time. The estimator must give a reasonable allowance for re-taping

* stick-on mouldings
* nameplates, and
* scripts.
