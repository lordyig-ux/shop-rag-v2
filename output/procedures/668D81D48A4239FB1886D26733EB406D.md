# ICBC refinish times not in the database for vans

A list of refinish times not in Mitchell Cloud Estimating (MCE) for vans.

### Refinish times not in MCE

The table presents refinish times for van parts that are not listed in the MCE database. They must be applied manually.

| Part | Refinish time for small van | Refinish time for large van |
| --- | --- | --- |
| Steel bumper | 1.5 | 1.5 |
| Plastic bumper (small/large) | 1.5/2.9 | 1.5/2.9 |
| Valance | 1.5 | 1.5 |
| Hood | 2.9 | 2.9 |
| Cowl vent panel | 1.5 | 1.5 |
| Fender | 2.9 | 2.9 |
| Door | 2.9 | 3.6 |
| Sill | 1.5 | 1.5 |
| Rear corner | 2.2 | 2.2 |
| Roof | 4.4 | 5.8 |
| Split cargo door right rear | 2.9 | 2.9 |
| Split cargo door side | 2.9 | 2.9 |
| Cargo sliding door | 3.6 | 4.4 |
| Rear lift gate | 3.6 | 4.4 |
| Left hand side full panel | 5.1 | 5.8 |
| Left hand or right rear side short panel | 3.6 | 4.4 |
| Adjacent panel overlap (major panels only) | 0.7 | 0.7 |

### Component refinish times

The following refinish times apply for complete refinishes for vans not listed in the MCE database.

| Component | Refinish time for small van | Refinish time for large van |
| --- | --- | --- |
| Complete refinish outside | 24.8 | 27.7 |
| Additional time for each painted bumper (when performing complete or component refinish) | 1.5 | 1.5 |
| Additional time for a different bumper colour (when performing complete or component refinish) | 0.7 | 0.7 |

Refinish times must be:

* in accordance with the current paint agreement, or
* included in the applicable ICBC refinish times not in MCE.

The estimator must use manual entry judgment times, when refinish times are not:

* listed in the paint agreement
* in MCE, or
* the applicable paint chart.
