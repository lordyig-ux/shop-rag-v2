# Incorrect and manual labour codes in estimating system

Steps for an estimator to enter labour operations in Mitchell Cloud Estimating (MCE).

### When this applies

The estimator or collision repair program participant must not change labour/rate codes associated with any labour operations in MCE.

ICBC uses flat rate times as listed in the Mitchell software. If no times are listed, then the estimator’s own judgment time must be used.

### Procedure

1. Enters the specific labour operation(s) in MCE.

   | If entry for a specific labour operation in Mitchell ... | Then ... |
   | --- | --- |
   | exists | do not create a manual entry in MCE. |
   | does not exist | * create a manual entry, and * re-classify the labour code and rate code using a similar operation that is listed in MCE. |
   | is incorrect | submit an email to the Editorial Team to Mitchell. |
2. Complete the task.
