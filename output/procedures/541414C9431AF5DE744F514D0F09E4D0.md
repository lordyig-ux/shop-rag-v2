# ICBC refinish times not in the database for cars

A list of refinish times and component refinish times that are not listed in Mitchell Cloud Estimating (MCE) for cars.

### Refinish times not in MCE

The table presents refinish times on car parts that are not listed in the MCE database. They must be applied manually.

| Part | Refinish time |
| --- | --- |
| Steel bumper | 1.5 |
| Plastic bumper (small/large) | 2.8 |
| Valance | 1.5 |
| Hood | 2.9 |
| Header | 2.2 |
| Cowl vent panel | 1.5 |
| Fender | 2.9 |
| Door | 2.9 |
| Sill | 1.5 |
| Quarter panel – 4 door | 2.9 |
| Quarter panel – 2 door | 3.6 |
| Trunk/hatch lid | 2.9 |
| Rear end panel | 1.5 |
| Roof | 4.4 |
| Adjacent panel overlap (major panels only) | 0.7 |

### Components refinish times

The table presents refinish times on car components that are not listed in the MCE database:

| Component | Refinish time |
| --- | --- |
| Complete refinish – compact | 20.4 |
| Complete refinish – midsize | 23.3 |
| Complete refinish – full | 26.2 |
| Additional time for each painted bumper (when performing complete refinish) | 1.5 |
| Additional time for a different bumper colour (when performing complete refinish) | 0.7 |

Refinish times must be:

* in accordance with the current paint agreement or
* included in the applicable ICBC refinish times not in MCE.

The estimator must use manual entry judgment times, when refinish times are not:

* listed in the paint agreement
* in MCE or
* the applicable paint chart.
