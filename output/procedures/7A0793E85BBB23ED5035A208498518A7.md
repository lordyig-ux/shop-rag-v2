# Autosource

Definition of Autosource.

### Definition

Autosource is an independent valuation service provided to ICBC by Audatex. It comprises a comprehensive vehicle database that is updated each week using vehicle data gathered daily from multiple sources. Autosource is the primary source for determining actual cash value (ACV) for vehicles.

Note: The WorkCenter Total Loss Valuation Report has replaced Autosource as the primary valuation service for ICBC as of June 2017, but Autosource is still used for valuations prior to that date.

### Data sources

Autosource:

* gathers data from all the following sources
  + dealerships
  + automotive guides
  + websites
  + industry publications, and
  + classified advertisements, and
* researches the market through physical inspection and telephone contact to determine local trends.

### Use of Autosource

All actual cash value (ACV) valuations must be completed using Autosource. When Autosource cannot complete the requested valuation, then a manual ACV should be completed.

When a vehicle settlement representative (VSR) is involved in a claim, the Estimator must review the Autosource ACV prior to releasing it to them.
