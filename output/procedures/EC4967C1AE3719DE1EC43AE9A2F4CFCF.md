# Lock cylinder recoding rates

Guidelines for lock cylinder recoding rates.

### Recoding rates

ICBC pays pre-determined rates for recoding a vehicle’s lock cylinder. The rate varies depending on the type of lock being recoded.

The table presents the rates applicable for each type of lock.

| Type of lock cylinder | Rate |
| --- | --- |
| Standard door or trunk lock | $45.00 |
| Standard ignition | $60.00 |
| High-security door or trunk lock | $65.00 |
| High-security ignition | $95.00 |
