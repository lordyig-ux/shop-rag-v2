# Minimum refinish allowance

Summary on eliminating the minimum refinish allowance for estimates.

### Minimum allowance

ICBC no longer adopts the minimum paint allowance and uses the Mitchell Cloud Estimating (MCE) refinish times for estimating.

No minimum refinish time applies to ICBC estimates.

The time that applies is

* the actual MCE time, or
* when no MCE time is available, the estimator uses a reasonable judgment time.
