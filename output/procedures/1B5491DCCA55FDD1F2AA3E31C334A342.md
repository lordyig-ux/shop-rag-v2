# Contents of a documents only arbitration package

List of items in a documents only arbitration package.

### Package contents

When entering arbitration, a documents only package must be created by the Manager, Estimating Services.

The package includes:

* a covering letter to arbitrator stating offer
* recent repair invoices
* vehicle valuation report and/or manual actual cash value (ACV) (newspapers, dealer quotes, etc.)
* vehicle images, and
* a summary (any additional notes you may have on valuation or negotiation).
