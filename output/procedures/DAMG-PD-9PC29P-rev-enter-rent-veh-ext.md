# Review an Enterprise Rent-A-Car extension request

The claims support assistant (CSA) must review and approve the rental vehicle extension request before submitting authorization.

### Prerequisites

ClaimCenter has created one of the following activities and assigned it to the Enterprise Rent-A-Car queue:

* [Enterprise Extension Request activity](CCUG-RF-J5A04X-enterprise-extension-request.html "The activity is created when an extension request is received from 's into .")
* [Enterprise Extension Request - Pended activity](CCUG-RF-KK40J2-enterprise-exten-req-pended.html "The activity is created when an extension request is received from 's Automated Rental Management System (ARMS) into . The rental status is updated as “Pended.”")

### When this applies

ICBC receives a request to extend a rental vehicle from Enterprise Rent-A-Car.

### Procedure

1. Review the Enterprise Request for Extension note details for the number of extension days requested.
2. Confirm the following: 

   * Rental coverage
   * Rental start date
   * Number of days authorized
   * Estimate repair time

   Note: If there are any concerns about extending the rental, the CSA reviews the Rental Notes tab to determine if the vehicle damageclaim owner or exposure owner has approved the extension and contacts the vehicle damageclaim owner or exposure owner if necessary.
3. Use the Rental calculator to confirm how long the customer is entitled to be in the rental.
4. Determine the scenario.

   | If the extension request is ... | Then ... |
   | --- | --- |
   | approved | edit the applicable Rental Authorization Details in the Rental Authorization tab. Note: For further information on approving an extension request, refer to the procedure, [Approve an Enterprise Extension Request](Topic.aspx?rootmap=ClaimCenter-user-guide&topic=CCUG-PD-865233-ext-ren-auth-entrprs "Process a rental vehicle extension request from in ."), in the ClaimCenter User Guide. |
   | not approved | * edit the applicable Rental Authorization Details in the Rental Authorization tab Note: For further information on finalizing a rental, refer to the procedure, [Set Last Day for a rental authorization with Enterprise Rent-A-Car](Topic.aspx?rootmap=ClaimCenter-user-guide&topic=CCUG-PD-ZT2Z5I-00-finalize-rental-auth-enterprise "When a customer no longer qualifies for the rental vehicle, the claims support assistant must set the last day to finalize the rental authorization with preferred supplier, through the Rental Authorization tab."), in the ClaimCenter User Guide. * update notes in ARMS, if needed, and * email Enterprise Rent-A-Car, if needed. |
5. Add the appropriate Rental Vehicle Note in the Rental Authorization tab.
6. Confirm the appropriate reserve line for Loss of Use is open.

   Note: Create the appropriate reserve line if required.
