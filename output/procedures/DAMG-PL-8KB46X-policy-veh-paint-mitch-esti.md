# Painting a vehicle not found in the Mitchell database policy

Guidelines on painting a vehicle not found in the Mitchell Cloud Estimating (MCE) database.

### Policy

When preparing a repair estimate for a vehicle model not found in the MCE database, the closest model to the vehicle from the same manufacturer with similarities in panel size is to be used. Remarks must be made on the repair estimate detailing what vehicle model is being used in place of the actual vehicle.

Note: If a similar model of vehicle is not available, refer to the [paint times chart](https://www.icbc.com/partners/material-damage/mdprocedures/Pages/topic.aspx?rootmap=DAMG-MP-NRP91J-vendors&topic=541414C9431AF5DE744F514D0F09E4D0&dm=MD%20partner%20procedures). Ensure that the correct chart is used, as there are different charts for cars, pick-up trucks and vans.

### Multiple water-based colours

Water-based paints with multiple colours cannot be applied and clear-coated in one application. Each base colour requires a clear coat application between each base colour before it can be masked off for the next base colour. Larger two-tone clear-coated panels require extra set up time and a second clear coat.
