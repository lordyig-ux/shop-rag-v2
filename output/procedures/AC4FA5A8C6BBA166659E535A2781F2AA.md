# Request non-appointment estimate for customer unable to attend

How to notify an estimator for a customer unable to attend an repair estimate appointment.

### Prerequisites

The customer’s vehicle requires an repair estimate but the customer cannot attend an estimating appointment at a claim centre.

### When this applies

An estimator must be notified if a customer’s vehicle needs an repair estimate but the customer cannot attend an repair estimate appointment.

### Procedure

1. Create a material damage activity.

   * Select the Non -Drive Estimating Assignment activity, and
   * rename it to No Appointment Estimate.
2. Modify the activity.

   * Rename the description to customer cannot attend any available appointments, and
   * add additional information as to why the customer cannot attend.

   **Example:**  

   Customer cannot attend any available appointments.
3. Set the assignment location in the activity to the customer's location.
4. Assign the activity to the Estimating Assignment Queue, using automated assignment.

   **Result:**  

   The estimator then makes the necessary arrangements to assist the customer.
