# Mitchell Connect error messages

Provide a collision repair program facility with instructions to resolve an error message they received in Mitchell Connect.

### Overview

Mitchell Connect generates specific error messages, and a collision repair program facility may request assistance to correct them.

Note: In these error messages, "carrier" refers to ICBC.

### Error messages and instructions

| Error message | Instructions |
| --- | --- |
| **Searching for a Claim** | |
| No valid assignments were found for the given search criteria. | Ensure the Claim Number, including dashes and suffix ID, and the Registration Number have been entered correctly.  Example:  * Claim Number: EA12571-2-A * Registration Number: 10455600  Note: The error message, "Claim number cannot contain special characters" will display when a space is used instead of a dash (-) in the claim number. If the error message is displayed even after the claim number has been entered correctly, the claim does not have an repair networkMethod of Inspection (MOI) created. Submit a Repair Facility Support Request form - Technical Inquiry for support. |
| The entered claim/BC Reg ID (or BC Reg Number) combination cannot be found. |
| This claim requires an estimate from a carrier certified service center. The customer can contact the carrier to arrange an appointment. | Contact MD Tech via [Repair Facility Support Request infographic](https://www.icbc.com). |
| **Assignment Error Messages** | |
| The assignment could not be requested because it is currently on hold. Please contact the carrier for assistance. | Ask the customer to "contact your claims representative". |
| This assignment requires specialization not currently on file for the shop. Contact the carrier for more information. | Contact MD Tech via the [Repair Facility Support Request infographic](https://www.icbc.com). |
| This assignment is not associated with the special holding dispatch group. Please contact the carrier for assistance. |
| The assignment could not be requested because this claim has been cancelled. | Submit a Repair Facility Support Request form - Technical Inquiry for support. |
| The claim could not be requested because there are no assignments associated with it. Please contact the carrier for assistance. |
| The appraisal assignment is not associated with the shop Dispatch Center. Please contact the carrier for assistance. |
| The appraisal assignment is closed and no estimate is found. |
| The assignment could not be requested because it has been cancelled. |
| The appraisal assignment could not be requested because it is already assigned to another repair shop. Please contact the carrier for assistance. | Submit a Repair Facility Support Request form - B sheet - Facility Change |
| The Appraisal Assignment is already pulled by the shop. | Someone in your own repair facility has already pulled the assignment. Check the job list to verify. |
| **Repair Assignment Error Messages** | |
| The repair assignment could not be requested because it is already assigned to another repair shop. Please contact the carrier for assistance. | Submit a Repair Facility Support Request form - B sheet - Facility Change |
| The repair assignment could not be requested because it is already sent and assigned to this shop. Please contact the carrier for assistance. | Someone in your own repair facility has already pulled the assignment. Check the job list to verify. |
| The repair assignment could not be requested because the estimate is not yet approved. Please contact the carrier for assistance. | Someone in your own repair facility has already pulled the assignment. Check the job list to verify. |
| The repair assignment could not be requested because it is marked as closed. Please contact the carrier for assistance. | Submit a Repair Facility Support Request form - Technical Inquiry for support. |
