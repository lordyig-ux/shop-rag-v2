# Overlap estimate

Overlap is an operation common to the replacement of more than one part. When overlaps occur, an overlap amount applies to the Estimate or Appraisal form.

### Applying overlap estimate amounts

Overlaps apply as follows:

| When all estimate operations being estimated are ... | Then ... |
| --- | --- |
| identified in Mitchell software | Mitchell Cloud Estimating (MCE) applies any overlaps. |
| not identified in Mitchell software | the estimator identifies and applies any overlap required. |
