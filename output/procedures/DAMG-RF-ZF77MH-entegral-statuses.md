# Statuses in Entegral

ICBC representatives, collision repair program participants, and glass repair program participants must understand the meaning of statuses in Entegral.

### Description

Each Entegral status describes something about the status of the application or profile within the collision or glass repair program.

| Status | Description |
| --- | --- |
| New | The facility has been linked to an ICBC program and is completing the application. |
| Terminated | The facility has been  * terminated or rejected from the program, and may have a re-entry date, and * removed from the applicable internal and external Repair Network Locators.   Note: The Supplier Programs and Administration (SPA) coordinator changes the tier to Non Supplier (NS) and sets the payment terms to Net 30. |
| Active | The facility  * is active in the program, and * appears in the applicable internal and external Repair Network Locators. |
| On Hold | The facility  * has had their program benefits suspended and may have a re-entry date, or * voluntarily exited the program and may have a re-entry date, and * has been removed from the applicable internal and external Repair Network Locators.  Note: The SPA coordinator changes the tier to NS and sets the payment terms to Net 30. |
| Ready for Review | The facility  * has been reviewed and accepted into the program * is not open for business at this time, and * is getting set up with access and training. |
| Under Review | The facility has been * placed in a Performance Review or referred to the supplier conduct committee (SCC), and * removed from external Repair Network Locators, but remains on the applicable internal Repair Network Locator.  Note:  * The SPA coordinator must select the Performance Review type. * SCC referral shows as Other in the drop down list. |
| Pending Confirmation | The participant has electronically signed and submitted their application to SPA.  Note: This status notifies the SPA manager that there is a new application for review. The manager assigns it to the SPA coordinator, who reviews the profile to determine if the facility meets the program requirements. |
