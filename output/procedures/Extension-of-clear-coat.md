# Extension of clear coat

Requirements to allow clear coat to the nearest panel edge or breakpoint.

### Definition

In some applications, it may be required to extend the application of clear coat to the nearest panel edge or breakpoint. This operation is not to be used when natural breakpoints exists (i.e. moulding belt line, convertibles).

Note: Multiple applications for the same panel can be applied (i.e. rocker and roof rail) but must be supported with photo documentation.

### Allowance

An allowance of 0.4 hours per operation at the current applicable Refinish rate based on the vendor status is to be applied for this operation. This can be done in the estimating system by adding the My Templates repair line "ICBC EXTENDED CLEAR COAT" to the estimate.
