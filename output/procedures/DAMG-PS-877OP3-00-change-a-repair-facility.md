# Changing a repair facility

Estimators or remote estimating support assistants are responsible for a repair facility change when required.

### When this applies

The customer decides to go to a new facility and the new collision repair program participant attempts to pull the repair estimate into Mitchell Connect, but receives the "The appraisal or repair assignment could not be requested because it is already assigned to another repair facility. Please contact the carrier for assistance." error message.

### Process

1. **Collision Repair Participant**
   1. Submits a Repair Facility Support Request form - General Request - B sheet.

      Tip: A collision repair program participant can access the Repair Facility Support Request form through [Make a support request (partners.icbc.com)](https://www.icbc.com/partners/material-damage/collision/pages/make-support-request.aspx).
2. **Estimator**
   1. Confirms with the original collision repair program participant that they are not financially invested (e.g. restocking fees for ordered parts, repairs have already started, etc.).
   2. Determines the scenario.

   | When the original collision repair program participant ... | Then the appraisal assignment is assigned to ... |
   | --- | --- |
   | has pulled the appraisal assignment and the repair estimate has not been submitted | the collision repair program participant and its disposition is "Dispatched". 1. Selects "Add New Suffix" from the Services screen in ClaimCenter. 2. Creates an Express Repair MOI. 3. Opens the original appraisal assignment and cancels it. 4. Informs the new collision repair program participant participant that they can retrieve the appraisal assignment for the newly created suffix. 5. Provides the new suffix ID to the collision repair program participant in order for them to request the correct assignment. |
   | has submitted a facility-written repair estimate that has been approved by an ICBC Estimator | the collision repair program participant and its disposition is "Completed". 1. Selects "Add New Suffix" on the Services screen in ClaimCenter. 2. Creates an Express Repair MOI. 3. Opens the original appraisal assignment and    * rejects it, if the option is enabled and    * cancels the current repair assignment. 4. Informs the new facility they can now retrieve the appraisal assignment for the newly-created suffix. 5. Provides the new suffix ID to the collision repair program participant in order for them to request the correct assignment. |
   | is working from an ICBC-written repair estimate | an estimator and its disposition is "Completed". 1. Selects "Add New Suffix" on the Services screen in ClaimCenter. 2. Opens the original appraisal assignment and    * rejects it, if the option is enabled, or    * cancels the current repair assignment. 3. Determines which one of the following actions to take:    * rewrites a repair estimate on the new suffix    * if the claim is not repair network qualified in ClaimCenter, completes a manual override and creates an Express Repair MOI or allow thecollision repair program participant to write the repair estimate, or    * if unable to express qualify, creates a one-line repair estimate on the new suffix to express enable the claim, and allow the repair participant to write a repair estimate. |

   Note: For further information, refer to the [Add and reassign new suffix](https://thehub/WorkTools/WorkToolsDocuments/Add-reassign-new-suffix.pdf) job aid.

### Results

The collision repair program participant change is completed and the new collision repair program participant can request the assignment.
