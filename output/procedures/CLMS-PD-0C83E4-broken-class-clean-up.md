# Handle broken glass cleanup on a collision estimate

A collision repair program facility estimator charges broken glass cleanup on a collision estimate.

### Prerequisites

There is broken glass in a vehicle from a loss that must be vacuumed.

### When this applies

Time may be warranted for vacuuming broken glass from a vehicle and removing parts for access when performed at a collision repair program facility using Mitchell Cloud Estimating (MCE).

### Procedure

1. Provide photos of the broken glass requiring vacuuming.
2. Navigate to the repair estimate in MCE.
   1. Click the Parts icon.
   2. Select the ICBC My Templates group, then 06 GLASS OPERATIONS.
   3. Select BROKEN GLASS CLEANUP.
   4. Add a line to the repair estimate.

      Note: If additional parts must be removed to get access to broken glass, those parts can be added as Remove & Install (R&I) on the estimate using applicable MCE times.
