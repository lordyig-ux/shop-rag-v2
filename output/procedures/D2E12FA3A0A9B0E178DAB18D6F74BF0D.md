# Emergency Roadside Expense Repayment tow invoice codes

A list of codes that represent the various services and service scenarios that took place at the time of the vehicle tow.

### Tow invoice codes

Sometimes Emergency Roadside Expense Repayment (ERER) applications for towing reimbursements and the accompanying tow receipts contain a variety of tow invoice codes.

The following lists the tow invoice codes and the respective descriptions.

| Code | Description |
| --- | --- |
| 215 | Drinking and driving  Note: The driver’s licence is usually under a 24 hour suspension. |
| 30 Day | Impound Lot Operator (ILO) program |
| Badge # | Police officer badge number |
| Bailiff | Repossession of vehicle  Note: The vehicle is usually under a court order. |
| Boost | Battery start |
| Bylaw | Vehicle ticketed by police or parking enforcement |
| Dept | Police department that called tow company |
| Flat Tire | Change tire |
| HFO | Hold for owner/registered owner |
| Investigation | Police investigation  Note: The vehicle is normally towed to a police yard. |
| MVA | Motor vehicle accident |
| NO D/L | No driver’s license |
| NO INS. | No insurance |
| Other | Vehicle search by police |
| PI | Private investigator  Note: This code could also mean private impound – illegally parked. |
| S/Keeping | Safe keeping  Note: Usually, vehicle shows forced entry. |
| S/R | Stolen recovered |
| Scrap | Tow to recycle yard |
| Street Move | Move vehicle to different area for city work crew |
| Ticket No. | Number on ticket written by police or parking enforcer |
| Unlock | Unlock Registered Owner’s Vehicle |
| Won’t Start | Tow to repair shop |
