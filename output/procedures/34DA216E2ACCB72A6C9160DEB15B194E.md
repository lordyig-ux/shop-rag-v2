# Types of losses that collision repair program participants confirm

Collision repair program facilities must confirm several types of losses to ensure vehicle damage is consistent with the reported loss as displayed in the Mitchell Connect assignment message.

### Types of losses

Collision repair program participants must confirm the type of loss for all comprehensive claims, including but not limited to

* animal impact
* falling object
* flying object
* paint over spray
* partial theft
* shifting cargo
* vandalism, and
* weather related
