# Tow request activity

Definition of a tow request activity.

### Definition

A tow request activity is

* manually or automatically created
* contains the following tow information:

  + vehicle origin
  + vehicle tow destination, and
  + special tow instructions, and
* assigned to the Tow Support queue or the Estimating Assignment queue.

It contains the required information that enables the requester to manage a tow of a vehicle.
