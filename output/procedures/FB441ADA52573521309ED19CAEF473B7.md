# Request ICBC review of collision repair estimate

A collision repair program facility flags an estimate for an ICBC review.

### When this applies

An ICBC customer with a collision repair program claim has contacted the collision repair program facility.

Note: The participant must flag the estimate for an ICBC review indicating that the estimate needs attention, when required.

### Procedure

1. Complete the estimate, meeting requirements defined in the

   * Material Damage claim procedures, and
   * Collision Repair Program Guide.
2. Determine if an ICBC review is required.

   | If an ICBC review of the estimate or supplement is ... | Then ... |
   | --- | --- |
   | required | * add the \* REQUIRES REVIEW \* long expansion repair line from the ICBC My Templates group. Note: This causes a compliance failure. * enter comments/remarks supporting the claim in the Estimate Remarks section, providing an applicable compliance failure explanation in Estimate Advisor to indicate what requires review on the estimate * check the Request Review checkbox, when adding the completed estimate in Mitchell Connect to submit to ICBC, and * submit the estimate to ICBC. |
   | not required | submit the estimate. |

   Important: When a participant flags the estimate with “Requires Review” for a specific purpose and an estimate or supplement is manually approved, items outside of the specific review requested may be modified at a later date. For information on review threshold estimates, refer to the topic [Repair program facility performance reviews](DAMG-RF-7LKSMF-rep-prgm-fac-perf-review.html "ICBC uses performance reviews as a performance management tool to ensure that collision repair program participants are complying with ICBC policies and standards.").
