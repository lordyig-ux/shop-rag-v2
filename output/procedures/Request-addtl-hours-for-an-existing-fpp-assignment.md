# Request additional hours for an existing Financial Partners Program assignment

Steps to request allocation of additional hours for a (work) phase of the Financial Partners Program (FPP), for existing FPP assignments (i.e. claims that were assigned to the FPP prior to March 9, 2017).

### Prerequisites

Adjusters or defence counsel have determined that they require allocation of additional hours that exceed the permitted hour authorizations identified in the policy, Policy on managing existing Financial Partners Program assignments.

### When this applies

Adjusters or defence counsel may need to request additional hours if a file has become larger in scope.

### Procedure

1. Determine if the work should be allocated to another phase of the FPP, instead of requesting additional hours.

   | If ... | Then ... |
   | --- | --- |
   | yes | refer to procedure, Allocate file to a different work phase for an existing Financial Partners Program assignment |
   | no | proceed to step 2. |
2. Request approval. 

   | If the request is by ... | Then ... |
   | --- | --- |
   | an adjuster | obtain approval from the adjuster's manager. |
   | defence counsel | obtain approval from the: * adjuster, or * adjuster's manager. |
3. Create a note in ClaimCenter to document the approval.
