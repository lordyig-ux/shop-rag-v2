# Creating an estimate in Mitchell TruckMax

The ICBC estimator or appraiser creates estimates which are supplemented by the Commercial Collision Repair participant.

### When this applies

When an estimate is being created by the estimator or appraiser using Mitchell TruckMax.

### Process

1. **ICBC estimator/appraiser**
   1. Creates Mobile Inspection MOI through ClaimCenter Services Tab, assigning to self.
   2. Adds COMMERCIAL REPAIR PROGRAM ENABLED ESTIMATE from the MY Templates line in Mitchell Cloud Estimating (MCE).
   3. Completes and sends estimate to WorkCenter (WC)
   4. Selects Re-open Review in WC
2. **Repair facility**
   1. Opens assignment to MCE.
   2. Supplements COMMERCIAL REPAIR PROGRAM ENABLED estimate and reviews loss details
   3. Writes estimate, attaching photos and artifacts.
   4. Enters Journal Note.
   5. Sends estimate package to ICBC for review.
