# Acceptable component refinishing times

Acceptable component refinishing times in Mitchell Cloud Estimating (MCE).

### Acceptable component refinishing times

The only component times in MCE that ICBC accepts are those listed for complete refinishing jobs.

Important: Times listed for other components must not be used.

### What to use instead

Estimators are to use the following times:

| When individual panel refinishing times ... | Then the estimator uses ... |
| --- | --- |
| are listed in the MCE database | the listed individual panel refinishing times. |
| are **not** listed in the MCE database | the ICBC refinishing time for the panel. |
