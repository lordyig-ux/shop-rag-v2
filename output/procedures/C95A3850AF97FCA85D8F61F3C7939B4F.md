# Flat laminated windshield installation times not in systems

Estimators must apply specific labour times when flat laminated windshield installation times are not in Glass Web Express (GWE) or National Autoglass Specifications (NAGS).

### Labour times

Most labour times for installation are available in GWE or NAGS. When the installation time is not in one of these systems, specific labour times are applied as follows.

| Installation type | Hours per windshield |
| --- | --- |
| Urethane set installation | 3.0 |
| Rubber moulding installation | 2.0 |
