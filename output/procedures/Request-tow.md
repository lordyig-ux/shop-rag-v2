# Request a tow

Claims support assistants (CSA) may request a vehicle tow from a tow company.

### When this applies

When a request to tow a vehicle has been received by the claims support assistant. Tow requests can be made by

* phoning the tow company, or
* completing and sending via email or fax, an External Tow Dispatch Request (CL602) form.

The following information should be provided, regardless of method

* claim number
* vehicle's year, make or model
* current location of vehicle
* current location of the vehicle's keys, if available
* number of sets of keys
* location that the vehicle should be towed to, and
* condition of vehicle, such as missing tires, or fire damage.

### Procedure

1. Contact the tow company via desired method.
2. Add an entry in the Vehicle Incident screen in ClaimCenter, providing the tow request details.

   Note: Refer to the ClaimCenter user guide topic, Add the vehicle location, for information on how to add the entry in ClaimCenter.

### Results

The tow company receives the tow request and initiates the tow.
