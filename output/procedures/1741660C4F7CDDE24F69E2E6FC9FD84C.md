# Class A bus and tour bus windshield installation times

List of Class A bus and tour bus windshield installation times not in the National Autoglass Specifications (NAGS) Calculator.

### Pre-authorization requirement

Provincial Glass Operations (PGO) must pre-authorize claims that require replacing large curved windshields on Class A buses and Class A Motorhome where no labour time is indicated in the NAGS Calculator.

### Labour times

The table presents windshield installation types and labour times.

| Windshield installation type | Labour times |
| --- | --- |
| Urethane set installation: One piece windshield | 12 hours |
| Urethane set installation: Two piece windshield | 6 hours per side |

Note: Anything falling outside the posted schedule must be pre-authorized by PGO, with all exceptions managed on a case by case basis.
