# Allocate file to a different work phase for an existing Financial Partners Program assignment

Steps to allocate a file to a different (work) phase of the Financial Partners Program (FPP), for an existing FPP assignment (i.e. a claim that was assigned to the FPP prior to March 9, 2017).

### Prerequisites

Claims specialists or adjusters have determined that a file needs to be allocated to a different phase of the FPP, in accordance with the policy, Policy on work phase requirements for existing Financial Partners Program assignments.

### When this applies

Claims specialists or adjusters may need to allocate a file to a different phase of the FPP, depending on the work effort required for the file.

### Procedure

1. Determine the phase that the file needs to be allocated to.

   | If the file needs to be allocated to ... | and the request is by an ... | Then ... |
   | --- | --- | --- |
   | * Phase 2 * Phase 4, or * Phase 5 | senior claims specialist | * allocate the file to the applicable phase, and * proceed to step 4. |
   | * claims specialist * customer claims specialist, or * adjuster | proceed to step 3. |
   | Phase 3 | * claims specialist * customer claims specialist, or * adjuster | proceed to step 2. |
2. Determine if Phase 2 of the FPP has been completed. 

   | If ... | Then ... |
   | --- | --- |
   | yes | proceed to step 3. |
   | no | * allocate the file to Phase 2, and * proceed to step 4. |
3. Obtain manager approval to allocate the file to the applicable phase.
4. Create a note in ClaimCenter to document the:

   * allocation to a different phase of the FPP, and
   * permitted hour authorizations for the phase allocated, as identified in the policy, Policy on managing existing Financial Partners Program assignments.

   Note: If the allocation is to Phase 3, ensure the note identifies that manager approval has been obtained.
