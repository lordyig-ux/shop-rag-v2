# Check the tow details on a tow request

Steps to retrieve tow requests and check the details to ensure that all required information is complete.

### When this applies

When claims support assistants retrieve tow requests and check the details to ensure all required information is complete.

### Procedure

1. Filter and retrieve tow activities for your location only from one of the following queue sources:

   * the estimating assignment queue, or
   * the tow support queue.
2. Check the following tow request information:

   * description which includes:
     + current vehicle location, and
     + vehicle tow destination.
3. Determine whether the tow request is complete.

   | If the tow request ... | Then ... |
   | --- | --- |
   | is complete | proceed with the vehicle tow. |
   | is not complete | conduct the appropriate research to identify missing information. |
