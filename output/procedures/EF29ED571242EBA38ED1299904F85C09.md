# Request copy of Estimate/Appraisal

How to schedule an activity to request a copy of the Estimate or Appraisal form.

### When this applies

When the activity is scheduled, generates the copy of the Estimate or Appraisal form and cover letter.

### Procedure

1. Request a copy of the Estimate or Appraisal form.
2. Schedule a new reminder activity.
3. Assign it to the Admin queue Claims Contact Centre 63 (CC63).
4. Enter CC63 as assignment location

### Results

The description field sends the Estimate or Appraisal form and cover letter.
