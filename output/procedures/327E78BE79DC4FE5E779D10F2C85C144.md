# Actual cash value source manuals

List of actual cash value (ACV) source manuals to review for determining an ACV manually.

### Sources

Sometimes it is necessary to determine ACV manually. This is done using secondary vehicle valuation sources.

The following sources can all be used to determine ACV manually

* Total Loss Provider Market Search
* Hemmings Motor News, and
* internet websites such as
  + Kijiji
  + Autotrader
  + Craigslist
  + Car gurus, and
  + Canadian BlackBook.

    Important: Sources from internet websites must include the make, model, trim, and vehicle photos.

### Details on selected sources

The following sources are particularly useful for determining a manual ACV:

| Source | Description and use |
| --- | --- |
| Black Book | The [Black Book](https://icbc.canadianblackbook.com/icbc/) (external) is a popular source of information for understanding the ACV of a vehicle when adequate information is not available through market value research. |
| Dealer quotes | All dealer quotes must be  * obtained through the sales manager of a dealership * documented with the dealership name, sales manager’s name and the contact phone number, and * based on the best cash/no trade price. |
