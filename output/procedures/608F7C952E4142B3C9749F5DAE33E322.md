# ICBC refinish times not in the database for pick-up trucks

A list of refinish times not in Mitchell Cloud Estimating (MCE) database for pick-up trucks.

### Refinish times not in MCE

The table presents refinish times on pick-up trucks parts that are not listed in the MCE database. They must be applied manually to MCE.

| Part | Refinish time for small pick-up truck | Refinish time for large pick-up truck |
| --- | --- | --- |
| Steel bumper | 1.5 | 1.5 |
| Plastic bumper (small/large) | 1.5 | 1.5 |
| Valance | 1.5 | 1.5 |
| Hood | 2.9 | 3.6 |
| Cowl vent panel | 1.5 | 1.5 |
| Fender | 2.9 | 2.9 |
| Door | 2.9 | 2.9 |
| Sill | 1.5 | 1.5 |
| Standard cab rear corner | 1.5 | 2.2 |
| Extended cab rear corner | 2.2 | 2.9 |
| Cab rear panel | 2.9 | 2.9 |
| Box front panel (bulkhead) | 1.5 | 1.5 |
| Box side panel | 2.9 | 3.6 |
| Tailgate | 2.9 | 2.9 |
| Roof | 3.6 | 4.4 |
| Adjacent panel overlap (major panels only) | 0.7 | 0.7 |

### Components refinish times

The following refinish times apply for complete refinishes for pick-up trucks not listed in the MCE database.

| Component | Refinish time for small pick-up trucks | Refinish time for large pick-up trucks |
| --- | --- | --- |
| Complete refinish outside | 21.9 | 24.8 |
| Additional time for each painted bumper (when performing complete or component refinish) | 1.5 | 1.5 |
| Additional time for a different bumper colour (when performing complete or component refinish) | 0.7 | 0.7 |
| Additional time for four door pick-ups, per side  Note: For complete refinish outside. | 2.9 | 2.9 |
| Additional time for extended cab pick-ups, per side  Note: For complete refinish outside. | 1.5 | 1.5 |

Refinish times must be:

* in accordance with the current paint agreement, or
* included in the applicable ICBC refinish times not in MCE.

The estimator must use manual entry judgment times, when refinish times are not:

* listed in the paint agreement
* in MCE, or
* the applicable paint chart.
